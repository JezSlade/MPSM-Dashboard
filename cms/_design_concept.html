Documentation (Architecture • OOP • Extensibility)

Mission — ultra‑light, zero‑dependency CMS dashboard skeleton adhering to OOP/SOLID/DRY. Everything is deliberately minimal, explicit, and scalable.

Concepts

  • WidgetModel — 10-field domain object (id, title, description, contentType, content, contentUrl, refreshInterval, widthUnits, heightUnits, tags).
  • WidgetRepository (interface) — persistence strategy. LocalStorageWidgetRepository (default). ApiWidgetRepository (REST-ready stub).
  • DashboardService — business logic (CRUD, order, refresh scheduling).
  • DashboardView — renders grid; delegates drag/reorder to DragManager.
  • DragManager — handle-only (widget header) reordering; persists order.
  • EventBus — tiny pub/sub decoupling UI & domain.

Storage & Order

Default persistence key cms.widgets.v1 in localStorage. Order is preserved by the array index and re-saved on drop.

Content Hooks

Three modes: html (inline srcdoc), url (iframe src), server (fetch HTML from PHP and render via srcdoc). Use the Content URL to point at your PHP endpoint. CORS must be allowed.

Scalability

  • OOP boundaries allow swapping repos, views, or policies without touching others.
  • UI is skeletal; all nodes carry BEMish classes and data-ui hooks for theming.
  • No implicit globals; everything is namespaced within the module.

Backend Scaffold (PHP • basic CRUD • zero deps) 
// api/index.php
<?php
require __DIR__ . '/WidgetsController.php';
$path = $_SERVER['REQUEST_URI'];
$method = $_SERVER['REQUEST_METHOD'];
$controller = new WidgetsController();
header('Content-Type: application/json');
header('Access-Control-Allow-Origin: *');
header('Access-Control-Allow-Methods: GET, POST, PUT, DELETE, OPTIONS');
header('Access-Control-Allow-Headers: Content-Type');
if ($method === 'OPTIONS') { http_response_code(204); exit; }

if (preg_match('#^/api/widgets/?$#', $path)) {
  if ($method === 'GET') echo json_encode($controller->index());
  elseif ($method === 'POST') echo json_encode($controller->store(json_decode(file_get_contents('php://input'), true)));
  else http_response_code(405);
} elseif (preg_match('#^/api/widgets/([\w-]+)/?$#', $path, $m)) {
  $id = $m[1];
  if ($method === 'GET') echo json_encode($controller->show($id));
  elseif ($method === 'PUT') echo json_encode($controller->update($id, json_decode(file_get_contents('php://input'), true)));
  elseif ($method === 'DELETE') echo json_encode($controller->destroy($id));
  else http_response_code(405);
} else { http_response_code(404); echo json_encode(['error' => 'Not found']); }

// api/Domain/Widget.php
<?php
class Widget {
  public string $id;
  public string $title;
  public string $description;
  public string $contentType;
  public string $content;
  public string $contentUrl;
  public int $refreshInterval;
  public int $widthUnits;
  public int $heightUnits;
  public array $tags;
  public static function fromArray(array $d): self {
    $w = new self();
    $w->id = $d['id'] ?? uniqid('w_', true);
    $w->title = $d['title'] ?? '';
    $w->description = $d['description'] ?? '';
    $w->contentType = $d['contentType'] ?? 'html';
    $w->content = $d['content'] ?? '';
    $w->contentUrl = $d['contentUrl'] ?? '';
    $w->refreshInterval = intval($d['refreshInterval'] ?? 0);
    $w->widthUnits = max(1, intval($d['widthUnits'] ?? 1));
    $w->heightUnits = max(1, intval($d['heightUnits'] ?? 1));
    $w->tags = $d['tags'] ?? [];
    return $w;
  }
  public function toArray(): array { return get_object_vars($this); }
}

// api/Domain/WidgetRepository.php (interface)
<?php
interface WidgetRepository {
  /** @return array */
  public function all(): array;
  public function find(string $id): ?array;
  public function create(array $data): array;
  public function update(string $id, array $data): array;
  public function delete(string $id): bool;
}

// api/Infra/FileWidgetRepository.php
<?php
require __DIR__ . '/../Domain/WidgetRepository.php';
require __DIR__ . '/../Domain/Widget.php';
class FileWidgetRepository implements WidgetRepository {
  private string $file;
  public function __construct(string $file){ $this->file = $file; if(!file_exists($file)) file_put_contents($file, json_encode([])); }
  private function load(): array { return json_decode(file_get_contents($this->file), true) ?: []; }
  private function save(array $rows): void { file_put_contents($this->file, json_encode(array_values($rows), JSON_PRETTY_PRINT)); }
  public function all(): array { return $this->load(); }
  public function find(string $id): ?array { foreach($this->load() as $w){ if($w['id'] === $id) return $w; } return null; }
  public function create(array $data): array { $rows = $this->load(); $w = Widget::fromArray($data)->toArray(); $rows[] = $w; $this->save($rows); return $w; }
  public function update(string $id, array $data): array { $rows = $this->load(); foreach($rows as &$w){ if($w['id'] === $id){ $w = array_merge($w, $data); break; } } $this->save($rows); return $this->find($id); }
  public function delete(string $id): bool { $rows = array_filter($this->load(), fn($w) => $w['id'] !== $id); $this->save($rows); return true; }
}

// api/WidgetsController.php
<?php
require __DIR__ . '/Infra/FileWidgetRepository.php';
class WidgetsController {
  private WidgetRepository $repo;
  public function __construct(){ $this->repo = new FileWidgetRepository(__DIR__ . '/data/widgets.json'); }
  public function index(){ return $this->repo->all(); }
  public function show(string $id){ return $this->repo->find($id) ?? ['error' => 'Not found']; }
  public function store(array $data){ return $this->repo->create($data); }
  public function update(string $id, array $data){ return $this->repo->update($id, $data); }
  public function destroy(string $id){ return ['ok' => $this->repo->delete($id)]; }
}

Place a simple PHP endpoint that returns raw HTML for contentType=server (e.g., /api/render.php?id=...) if you prefer server-side composition.

Usage Notes & Conventions
  • Drag by the widget header to reorder. Order is persisted.
  • The inspector updates when you select a widget via the header’s ✎ button.
  • Preview renders the current form values into the panel iframe.
  • All elements carry semantic classes & data-ui hooks for styling/test automation.
