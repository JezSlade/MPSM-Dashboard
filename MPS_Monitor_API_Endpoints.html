MPS Monitor API Endpoints Reference
Quick Reference: HTTP Methods & Terms
  • GET — Retrieves information or data from the server (e.g., view a list or details).
  • POST — Sends data to the server to create something new (e.g., create a report or user).
  • PUT — Sends data to update or replace an existing record.
  • PATCH — Sends partial data to update part of a resource.
  • DELETE — Requests that a resource be removed from the server.
  • Endpoint — A URL path that connects to specific functionality of the API.
  • Method — The type of action performed on the endpoint (GET, POST, etc.).
  • Operation ID — A unique code-friendly name for the action the API performs.
  • Prefix — The first part of the endpoint that groups related functionality (e.g., /Device).
Overview

This is a comprehensive list of all available API endpoints for MPS Monitor including their methods and use cases. Each endpoint is designed to perform specific operations related to account management, device monitoring, analytics, and more. Select an endpoint from the table of contents below to view its details. Tables are sortable; click on the headers to sort by that column.
