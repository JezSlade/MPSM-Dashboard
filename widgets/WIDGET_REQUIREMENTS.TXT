WIDGET REQUIREMENTS FOR MPS MONITOR DASHBOARD
=============================================

This guide defines the mandatory architecture for all widgets in the MPS Monitor dashboard system.

1. FILE LOCATION & NAMING
-------------------------
- All widget files must be placed in:
  /widgets/{widget_name}.php

2. REQUIRED HEADER BLOCK
------------------------
Each widget file must start with:

<?php
// widgets/example.php

// Widget Name: Example Widget
// Widget Icon: fas fa-puzzle-piece
// Widget Width: 2.0
// Widget Height: 2.0

$_widget_config = [
    'name' => 'Example Widget',
    'icon' => 'puzzle-piece',
    'width' => 2,
    'height' => 2
];

3. SESSION BOOTSTRAP
--------------------
To ensure session access, include:
if (session_status() === PHP_SESSION_NONE) {
    session_start();
}

4. OUTPUT STRUCTURE
-------------------
All output must be returned from a render function, not echoed inline.

Example:
function render_example_widget() {
    ob_start();
    // ...HTML and logic...
    return ob_get_clean();
}

5. FINAL OUTPUT
---------------
Widgets must render via:
<?php echo render_example_widget(); ?>

Never use <?= ?> shorthand as it may output source code.

6. COMPACT AND EXPANDED MODES
-----------------------------
Each widget should define:
<div class="compact-content" style="display:none;">
    ... small preview ...
</div>

<div class="expanded-content" style="display:block;">
    ... full widget display ...
</div>

7. ALLOWED FUNCTIONS
--------------------
Allowed:
- Standard PHP
- file_get_contents(), file_put_contents()
- Constants like __DIR__, etc.

Prohibited:
- Includes from outside widget file
- Echoing output before render function
- HTML output outside render_*()

8. NAMING CONVENTIONS
---------------------
- Function name: render_{widgetname}_widget()
- File name: {widgetname}.php
- Config array: $_widget_config

9. OUTPUT SAFETY
----------------
Always sanitize any dynamic output using:
htmlspecialchars($output)

10. TEMPLATE SNIPPET
--------------------
<?php
// widgets/example.php

// Widget Name: Example
// Widget Icon: fas fa-bug
// Widget Width: 2.0
// Widget Height: 2.0

$_widget_config = [
    'name' => 'Example',
    'icon' => 'bug',
    'width' => 2,
    'height' => 2
];

if (session_status() === PHP_SESSION_NONE) {
    session_start();
}

function render_example_widget() {
    ob_start();
    echo "<div class=\"compact-content\" style=\"display:none;\">";
    echo "  <div class=\"text-muted\">Example Widget (Compact)</div>";
    echo "</div>";

    echo "<div class=\"expanded-content\" style=\"display:block;\">";
    echo "  <pre>Example output here</pre>";
    echo "</div>";
    return ob_get_clean();
}

?>
<?php echo render_example_widget(); ?>
